用户模拟审计（2026-11-28）的 advisor 交互修复：`/advisor status|doctor|on` 等命令回执现在**第一行就是用户实际敲的命令行**（宿主通用命令卡片只显示命令名、单行省略号截断，多行输出要点第二层折叠），并新增插件自己的命令卡片（`conversation.chat.commandview` 的 `advisor` 渲染器）显示原始命令行 + 完整多行输出、不省略；宿主会在本地命令执行成功后广播 `command/executed`，插件据此把多行输出放进右下角的**命令回执面板**（常驻到手动关闭，空白会话里也能看到）。设置页首屏的「模式」行新增**生效状态徽标**：保存的 `mode` 只是偏好，`advisory` 但没选模型时显示「已关闭：未选择顾问模型」，`/advisor status` 与 `/advisor doctor` 同样分开报「模式」（保存值）和「生效」（真实状态）；`/advisor on` 在未配置模型时不再偷偷把保存的 `mode` 改成 `advisory`。工具结果不再把「顾问已关闭 / 未配置 / shadow」这类内部开关状态交给主模型，改成中性跳过并明确要求模型不要把它写进给用户的回复。斜杠菜单里的命令描述改为中英双语（host 半自己读 `locale/*.json` 的 `host` 段，宿主没有 locale 服务），并统一了用户可见文案里的繁体字「徵询」→「征询」。
