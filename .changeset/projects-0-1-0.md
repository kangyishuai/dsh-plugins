首发版本（M1 + M2）：把「项目」做成并行工作的上下文单元。

**上下文**
- 项目仓储：数据根可注入、原子写、损坏文件改名隔离（不删除）、未来格式版本拒绝
- 项目级上下文注入：归属会话在每次请求前收到常设规则与 `MEMORY.md` 索引；
  16k 预算、按 agent 作用域注册、归档即摘除、不与宿主已加载的 AGENTS.md 重复

**并行工作**
- 线程隔离：项目中建线程时先建 Git worktree 再建会话（cwd 建后不可变）；
  非 git 目录或建失败一律降级为共享目录并给原因，不阻断
- 回收：归档即回收，但三重判据（脏工作区 / 有未推送提交 / 当前会话目录）任一命中就保留；
  启动时对账，磁盘上未记录的目录只报告、不删除
- Overview：五态（待你处理 > 失败 > 进行中 > 已完成 > 空闲）全部从持久会话事件推导，
  `replay` 可重启重建；面板按「需要我」优先排序

**边界与安全**
- 删除项目走回收站（ADR 0002）：dry-run 影响面（数量/体积/在跑/可恢复）、两段式确认、
  `manifest.json` 可恢复、写审计；会话日志全程不动
- 预算闸：每日线程数与并发上限（token 维度留待 M3）
- 暂停/恢复项目：可逆，不删除任何数据
- 无远端写入、无模型自调用、不读取凭据

**尚未发布**：协调器（wake / 路由 / 人格 / 自治）、auto PR、auto-fix、LiveShare 共享。
