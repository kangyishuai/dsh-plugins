# @kangyishuai/dsh-session-rewind

> DeepSeek Harness 的「就地回溯」：把会话退回到任意一条用户消息之前，目标消息及其后的内容同时从模型上下文和渲染对话中撤回；可选择一并还原这些轮次改过的工作区文件；目标消息文本（和图片）自动回填输入框。

非官方插件，与 DeepSeek 无关。面向 [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness)。

> **状态：早期。** 已在 DSH 0.2.2-rc.1 上端到端验证：185 个单测、一次性 DSH 目录里 34 项 GUI 断言、以及**真实桌面版 36 项断言**（只读界面 + 文件模式：新建文件进回收站、修改文件还原、救援点恢复、时间线）。`pnpm gate:session-rewind` 一条命令跑完发版门禁。插件还年轻，重要数据请自行备份。

## 它做什么

长对话会跑偏。几轮之后你希望当初换个问法，但新开一个会话会丢掉之前的全部上下文，继续聊又会让不想要的几轮永远占着上下文窗口。这个插件做**就地回溯**：

- **两个入口**：连按两次 `Esc` 打开回溯对话框；或点任意用户消息操作行里、复制按钮旁边的 ↶ 按钮。
- **每次回溯二选一**：确认框里提供「**仅回退对话**」（默认）与「**回退对话和文件**」，并先展示 dry-run 预览：将撤回多少条消息、约多少 token、哪些文件会还原/移入回收站、冲突与被跳过的文件。
- **对话**：目标消息及其后的内容从模型上下文和渲染对话中撤回；会话 id、标题和目标之前的历史不变；日志只追加一条 marker，不删历史。
- **文件（可选）**：被撤回轮次里由 `write` / `edit` / `apply_patch` 改过的文件还原到改动前内容；目标之后新建的文件移入插件回收站而不是删除。写入前先建救援点，失败从救援点回滚。
- **状态变更提示**：如果要撤回的区间里改过会话状态（plan 模式、goal、待办、模型选择、权限/沙箱预设、智能体预设、定时任务、工作目录），确认框会列出来并明确说明——回溯只撤回对话，**不会**回滚这些状态。
- **运行中也能回退**：确认回退时如果这一轮正在跑，会先取消它（保留队列）、等它空闲，再对新历史重新求值。
- **输入框**：目标消息文本（以及图片）放回输入框，改完可直接重发；已有草稿绝不覆盖。勾选「回退后立即重发」可一键重试这一轮（仅对话模式）。
- **多视图自动同步**：在一个标签页/窗口里回溯后，其它已打开的同会话视图会立刻隐藏被撤回的行，无需刷新（通知走 `localStorage`，渲染只认宿主 cuts）。
- **回溯面板**：会话头部新增一个入口，四个页签：**已撤回**（每次回溯撤回的全部消息，可搜索、复制、放回输入框）、**回溯记录**（时间线：每次回溯与每次救援点恢复，新在上；范围、条数、token、文件结果）、**救援点**（手动恢复文件）、**设置**（默认范围、每页数量、列表确认、诊断）。

## 只读 agent 工具

插件还会注册一个**只读**工具 `session_rewind_candidates`，让模型能自己判断「能退回到哪、退回去会丢什么」，但**不执行**回溯：

| 调用                                       | 结果                                                                 |
| ------------------------------------------ | -------------------------------------------------------------------- |
| `session_rewind_candidates {}`             | 按新→旧列出可回退的消息（`query` 过滤，`limit` 上限 50）。           |
| `session_rewind_candidates { target_seq }` | 单条消息的影响面：会撤回多少条、是否截断未完成的工具调用、目标文本。 |

这个工具不回溯、不碰文件、不写会话日志——真正的回退始终由用户在界面确认（这是 ADR 0006 的设计前提）。设 `readOnlyTool: false` 可关闭；**设置 → 诊断**里能看到它是否注册成功。

## 安装

```bash
dsh plugin --profile desktop add @kangyishuai/dsh-session-rewind
```

如果要用工作区里的代码而不是发布版，先打包再装——`link:` 装法不行（宿主的 `@deepseek-ai/*` 解析只覆盖真实路径位于 profile 内的包）：

```bash
cd packages/session-rewind
pnpm pack --pack-destination /tmp
dsh plugin --profile desktop add /tmp/kangyishuai-dsh-session-rewind-*.tgz
```

改完代码要重新 `pnpm pack` + `add`。插件带宿主半，装完重启 DSH 桌面版并刷新页面。

## 用法

**键盘 — `Esc` `Esc`。** 空闲会话里快速连按两次 Escape，打开回溯对话框：按时间倒序列出用户消息，可搜索、↑/↓ 选择、Enter 或点击；随后进入预览/确认框，选范围并确认。回合运行中 `Esc` `Esc` 保持原生「停止」含义；停下后再按两次即可。

**消息操作 — ↶。** 每条用户消息的复制按钮旁都有 ↶；点开同一个预览/确认框，确认后才执行。

**命令。** `/rewind` 打开同一份候选列表；`/rewind @<序号> [chat|both]` 直接执行（序号在列表里可见）。客户端会接管裸 `/rewind`，不会把命令发给模型。

**回溯之后**，目标文本回到输入框（图片尽力重新挂回）并获得焦点。如果输入框里本来有草稿，不会被覆盖，并会提示草稿已保留。

**会被拒绝的情况**

| 情况                                                        | 表现                                                                                                                      |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 会话有正在运行的回合                                        | 先取消该回合并等到 idle（队列里未投递的插话会被丢弃），再回溯；设 `cancelRunning: false` 则仍返回 `session-rewind/busy`。 |
| 子代理会话                                                  | 没有 ↶ 按钮，`Esc` `Esc` 也不弹框：宿主拒绝对这类会话的通用 RPC。                                                         |
| 目标消息已被 compaction 遮蔽                                | 拒绝；回溯边界必须仍在模型上下文里。                                                                                      |
| 文件在上次记录后被外部修改                                  | 文件模式整体拒绝并列出冲突文件；一个文件都不动。                                                                          |
| 文件超过 8 MiB、是符号链接、或在 `.git` / `node_modules` 下 | 该文件跳过并报告，其余文件继续。                                                                                          |
| 同一会话已有回溯在执行                                      | 拒绝；一次只允许一个。                                                                                                    |

## 文件还原的范围与安全

- **只追踪写类工具**：`write` / `edit` / `apply_patch`，且只限会话工作目录。`bash`、脚本、外部程序、子代理的改动**不在追踪范围**，插件不会声称做过完整工作区快照。
- **写前记录**：工具执行前记录内容，按 SHA-256 去重存到 `<DSH_HOME>/session-rewind/blobs/`。还原前逐个比对「当前内容」与「最后一次记录的 after」，不一致就整体中止并列出冲突。
- **先救援点、再写入**：还原前把当前受影响文件复制成救援点；救援点失败则一个字节都不写。恢复逐文件写回/移入回收站，写后校验哈希；失败用救援点回滚，回滚失败也会报告。每个会话保留最近 5 份救援点，可在回溯面板手动恢复（恢复前会再建一份救援点）。
- **删除走回收站**：目标之后新建的文件移入 `<DSH_HOME>/session-rewind/trash/<session>/<auditId>/`，不会 `rm`。超限/符号链接/被排除目录的文件保持原样并报告。
- **没有 undo**：本插件刻意不做真 undo/redo（那需要 patch 宿主内部）。被撤回的内容仍在会话日志和回溯面板里；文件层面可用救援点或回收站手动恢复。
- **顺序**：预览与冲突检查 → 建救援点 → 追加会话 marker → 写文件。marker 一旦写入，对话回退即生效；文件失败只报告并写审计，不回滚对话。

## 数据与保留

所有数据在 `<DSH_HOME>/session-rewind/`（`DSH_HOME` 默认 `~/.dsh`）：

| 路径                            | 内容                          |
| ------------------------------- | ----------------------------- |
| `blobs/`                        | 内容寻址的文件内容（SHA-256） |
| `sessions/<id>/entries.jsonl`   | 每个会话的文件改动记录        |
| `trash/<session>/<auditId>/`    | 回溯时新建文件的回收站        |
| `rescues/<session>/<rescueId>/` | 还原前的救援点                |
| `audit.jsonl`                   | 每次回溯一行（只追加）        |

启动时会自动清理已删除会话的残留数据（entries/trash/救援点）；审计日志保留。保留策略：每会话最近 20 个消息锚点、最近 5 份救援点、最近 20 次回收站操作（30 天）、blobs/trash/rescues 合计 1 GiB 软上限。超限时按「旧回收站 → 旧救援点 → 无引用 blob → 最旧锚点」清理；仍超限则停止新捕获并在诊断里告警（不删有引用的数据）。卸载保留数据。数据根可用插件配置 `dataRoot` 覆盖。

## 副作用与风险

- **每次回溯追加一条 marker** 到当前会话日志；不删除、不改写历史。
- **仅在文件模式下写/删工作区文件**，且经过确认与上述安全流程。
- **marker 对模型可见**：在被撤回回合的位置，模型会看到一条很短的 `(empty message)` user 消息；界面不显示它。
- **不联网、不上报**；文件快照可能含敏感内容，请把 `<DSH_HOME>/session-rewind/` 当工作区数据对待。
- **客户端私有 seam**：隐藏行和注入 ↶ 按钮依赖 DSH 内部 view/slot 注册表；安装时做形状检查，失效时降级为「上下文已回溯、界面不隐藏」或「按钮消失」，不破坏会话。
- **本版只验证 POSIX/macOS 路径**；Windows 分隔符与权限位未验证。
